# LumiCare H5 产品页

这是一个用于产品介绍的移动端 H5 页面，适合用于：

- 产品发布页
- 活动落地页
- 启动页/品牌宣传页
- 客户演示页

## 运行方式

在项目根目录执行：

```bash
python -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000/
```

## 文件说明

- `index.html`：页面结构
- `styles.css`：样式与响应式设计
- `script.js`：进入视口动画

## 可定制内容

- 品牌名称与 Logo
- 标题和描述文案
- 功能模块与数据指标
- CTA 按钮链接
- 附加配色、图标和图表风格

## 设计特点

- 适配移动端 H5 展示
- 现代渐变 UI
- 轻量无依赖，直接打开即可用
- 支持滚动触发动画
