# 童伴成长 APP 演示

这是一个可直接预览的儿童成长 App 静态演示页面，覆盖以下核心需求：

- 普通用户可用：每日计划表，例如起床、早餐、晨读、睡觉等。
- 小红花激励：完成任务后自动累计今日小红花数量。
- VIP 功能：孩子成长档案、A4 可打印练习题、添加第 2 到第 5 个孩子。
- 成长档案：记录孩子姓名、性别、年龄、身高、体重。
- 练习题：覆盖幼儿园到初三，支持选择年级并打印 A4 练习单。

## 如何查看 APP 演示页面

### 方式一：直接打开文件

在文件管理器中双击 `index.html`，浏览器会直接打开演示页面。现在脚本使用普通 `defer` 加载，不依赖打包器，也不需要安装依赖。

### 方式二：启动本地静态服务器

```bash
npm run dev
```

然后在浏览器访问：

```text
http://localhost:5173
```

> 如果本机 5173 端口被占用，可以使用 Python 指定其它端口，例如：`python3 -m http.server 8080`，然后访问 `http://localhost:8080`。

## 页面操作说明

1. 在“每日计划表”中勾选任务，可以看到小红花数量实时增加。
2. 想快速展示完整流程时，点击顶部“一键进入演示”，页面会自动解锁 VIP、完成所有任务、填入 3 个孩子档案并切到初一练习题。
3. 点击右上角“开通 VIP 解锁全部”，可以手动解锁成长档案和练习题区域。
4. VIP 状态下可以编辑孩子姓名、性别、年龄、身高、体重，并最多添加 5 个孩子。
5. VIP 状态下可以选择幼儿园到初三任一年级，点击“打印 A4 练习题”打印练习单。

## 演示数据保存

页面会把演示状态保存在浏览器 `localStorage` 中。刷新页面后，小红花、VIP 状态、孩子档案和选择的年级会继续保留。
